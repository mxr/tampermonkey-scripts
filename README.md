# tampermonkey-scripts

Personal Tampermonkey scripts for daily browser automation.

## Disclaimer

These scripts are unofficial personal automations and are not affiliated with, endorsed by, or sponsored by any website or company whose website they interact with or modify.

## Scripts

- `scripts/amazon-invoice-single-payment.user.js`: Consolidates a split payment into a single payment method and total on the Amazon order invoice print page.
- `scripts/etrade-login-security-code.user.js`: Automatically enables "Use security code" on the E*TRADE login experience.
- `scripts/linkedin-hide-feed.user.js`: Hides the LinkedIn home news feed.
- `scripts/parcel-qol.user.js`: Adds Parcel quality-of-life improvements including a days-left column, smart sorting, and delete confirmation.

## Usage

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the script file on GitHub.
3. Click `Raw` to open the Tampermonkey install page.
4. Click `Install`.
